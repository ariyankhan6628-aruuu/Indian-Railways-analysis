# Indian-Railways-analysis
# 🚆 Indian Railways Train Delay & Punctuality Analysis

## 📌 Project Overview

This project presents an interactive data analytics dashboard for analyzing **Indian Railway train delays and punctuality performance**.

The analysis focuses on train arrival performance across **10 major trains from 2016 to 2025**, helping identify delay patterns, route performance, punctuality trends, and trains with higher average delays.

## 🎯 Objectives

* Analyze train arrival delays.
* Compare punctuality across different trains.
* Identify routes with higher average delays.
* Analyze yearly delay trends.
* Understand different levels of delay severity.
* Compare scheduled and actual arrival times.
* Identify the best- and worst-performing trains.

## 📊 Dashboard Features

The interactive dashboard provides:

* **Total Journeys**
* **Average Delay**
* **On-Time Rate**
* **Worst-Performing Train**
* Year-wise average delay trends
* Train performance ranking
* Route-wise delay analysis
* Delay severity distribution
* Train running frequency
* Scheduled vs. actual arrival analysis
* Interactive filters for year, train, route, and delay status
